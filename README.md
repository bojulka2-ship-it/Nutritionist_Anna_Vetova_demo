# Лендинг «Анна Ветрова — врач-нутрициолог»

Одностраничный лендинг персонального сайта с формой записи, которая собирает заявки в **Google Таблицу** через веб-приложение Apps Script.

> **Демо-репозиторий.** Для безопасности сбор заявок в этой ветке отключён: `SHEETS_URL` в `index.html` пуст, форма работает в демо-режиме (показывает «успех» и пишет данные в консоль). Как подключить свою таблицу — см. [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).

## Возможности

- Адаптивный лендинг без внешних зависимостей: шрифты (woff2) и стили — локальные, нет CDN, аналитики и сторонних скриптов.
- Интерактив: услуг-аккордеон, квиз «30 секунд», карусель отзывов, таймер до конца месяца, маска телефона.
- Форма записи с защитой от спама и продуманной валидацией контактов (Telegram/WhatsApp/VK/MAX/e-mail).
- Сбор заявок в Google Таблицу: `apps-script/Code.gs` (разворачивается как веб-приложение).

## Структура

```
index.html                  Лендинг (весь сайт в одном файле, JS в конце)
apps-script/Code.gs         Серверный сборщик заявок (Google Apps Script)
tests/security.test.js      Набор тестов безопасности (Node.js, без npm)
docs/DEPLOYMENT.md          Пошаговое подключение Google Таблицы
docs/SECURITY.md            Обзор защитных механизмов и ограничения
screenshots/                Скриншоты: страница целиком, пример таблицы заявок
fonts/                      Локальные шрифты (Cormorant, Golos Text)
img/                        Фото (не входит в репозиторий, используется fallback)
```

## Быстрый старт

1. **Локально**: просто откройте `index.html` в браузере. Форма в демо-режиме: заявка не отправляется, данные формы видны в консоли (F12).
2. **Прогнать тесты безопасности** (нужен только Node.js):

   ```bash
   node tests/security.test.js
   ```

3. **Подключить реальный сбор заявок**: создайте Google Таблицу, разверните `apps-script/Code.gs` как веб-приложение и вставьте полученный URL в `const SHEETS_URL` в `index.html`. Подробная инструкция — [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).

## Демо-режим vs боевой режим

| | Демо (по умолчанию) | Боевой |
|---|---|---|
| `SHEETS_URL` в `index.html` | пустая строка `''` | ваш URL `https://script.google.com/macros/s/.../exec` |
| Поведение формы | «успех» + данные в консоли | POST в веб-приложение |
| Запись в таблицу | нет | да, строка в лист `Заявки` |

## Технологии

Чистый HTML + CSS + JS без сборки и зависимостей. Серверная часть — Google Apps Script (V8), таблица — Google Sheets.
