# Подключение Google Таблицы к форме заявок

Сайт собирает заявки через веб-приложение Google Apps Script. Ниже — полный путь от пустой таблицы до первой заявки. Один раз настроив, больше ничего открывать не нужно: скрипт работает в облаке даже при закрытой таблице.

## Что понадобится

- Аккаунт Google (личный), таблица создаётся в нём же.
- Код скрипта: файл `apps-script/Code.gs` из этого репозитория.

## Шаг 1. Создайте таблицу

1. Откройте `sheets.new`, назовите, например, «Заявки — Ветрова».
2. Ничего вручную заполнять не нужно: скрипт сам создаст лист `Заявки` с заголовками
   `Дата | Имя | Телефон | Способ связи | Контакт | Программа | Согласие`.

## Шаг 2. Создайте проект Apps Script, привязанный к таблице

1. В открытой таблице: меню **Расширения → Apps Script**. Откроется встроенный редактор
   (скрипт будет привязан именно к этой таблице — важно).
2. Удалите содержимое файла `Code.gs` (или `Мой файл`) и вставьте код из
   `apps-script/Code.gs` полностью.
3. **Сохраните** (Ctrl+S). Запустите любую функцию один раз (например, `testDoPost`),
   чтобы Google попросил разрешения: **Разрешить → аккаунт → Дополнительные настройки →
   Перейти → Разрешить**. Это нормально для личных скриптов.

## Шаг 3. Разверните как веб-приложение

1. В редакторе: **Развернуть → Новое развертывание → шестерёнка → «Веб-приложение»**.
2. Параметры:
   - **Описание** — любое, например «Форма заявок».
   - **Выполнять от имени: «Я»** — обязательно, иначе запись пойдёт от каждого анонима.
   - **Кто имеет доступ: «Все»** (Anyone) — чтобы форму могли отправлять посетители сайта
     без логина.
3. **Развернуть**. Из появившегося окна скопируйте **URL веб-приложения** —
   он заканчивается на `/exec`.

## Шаг 4. Вставьте URL в сайт

1. В `index.html` найдите настройку:

   ```js
   const SHEETS_URL = '';
   ```

2. Вставьте URL из шага 3:

   ```js
   const SHEETS_URL = 'https://script.google.com/macros/s/ВАШ_ДЕПЛОЙ/exec';
   ```

3. Обновите страницу (**Ctrl+F5**), отправьте заявку с реальными данными —
   строка появится в листе `Заявки`.

## Если вы меняли код скрипта

Apps Script кэширует версии. После правок `Code.gs`:

**Развернуть → Управление развертываниями → карандаш → «Версия: Новая» → Развернуть.**

URL веб-приложения при этом **не меняется** — на сайте править ничего не нужно.

## Диагностика «заявка не дошла»

1. Откройте таблицу и проверьте лист **`Заявки`** (не «Лист1»).
2. Убедитесь, что форма находится в **боевом** режиме: `SHEETS_URL` не пуст.
3. Смотрите консоль браузера (F12) и панель **Выполнения** в Apps Script — там логи скрипта.
4. Если повторно отправляете **одинаковые имя+телефон** — вторая заявка намеренно
   не дублируется (защита от дублей, ответ `{ok:true, dup:true}`) — это не поломка.
